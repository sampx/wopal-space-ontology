# README 参考 — 项目 README 编写

创建或更新项目 `README.md`。模板内联如下。

## 文档路径与命名

- 项目级：`<project>/README.md`。
- 用户偏好语言非英文时，先在同目录创建 `README.<locale>.md` 供审核；确认后更新 `README.md`。
- `<locale>` 使用 IETF BCP 47 / RFC 5646 标签（如 `README.zh-CN.md`）。
- 正式英文版保持文件名不变 `README.md`。不生成 `README.en-US.md` 之类的英文变体。

## 目的

`README.md` 是人读的项目入口文档。它解释项目是什么、如何安装与运行、能做什么、以及到哪里找持久参考。它不是 Agent 规则文件、不是实现清单、也不是设计规格。

## 前置条件

生成前优先阅读：既有 `README.md`、关联 PRD、关联 DESIGN、项目 `package.json` / 构建 / 运行配置、主入口文件或 CLI 命令定义、license 文件或包元数据。

## 核心规则

- 为人类读者写作，语气友好。
- 快速上手与核心能力放在前面；开发命令与参考链接放在后面。
- 列出模块与核心入口命令；不枚举每个子命令。完整用法指向 `--help`。
- 不深入内部实现细节或 Agent 专属实现规则。
- 技术栈与项目结构属于 DESIGN / AGENTS.md；不在 README 中重复。
- 所有命令必须从 package / 配置文件验证。绝不猜测。
- 末尾 Technical References 承载仅参考文档（设计、产品文档、持久参考）。它们是信息链接，绝非强制跟随链接。不在一份文档中既出现在正文又出现在 Technical References。

## README 模板

```markdown
# <Project Name>

<One-paragraph human-facing description.>

## Quick Start

```bash
<install command>
<run command>
```

## Core Capabilities

| Module | Entry Commands | Purpose |
|---|---|---|

## Development

| Scenario | Command |
|---|---|

## Technical References

| Document | Description |
|---|---|

## License

<license>
```

## 写作质量线

- 用一段清晰的开场段落解释项目价值。
- 快速上手：可执行的安装与运行命令。
- 核心能力：按模块，不带实现细节。
- 开发命令：简洁表格，来源已验证。
- 技术参考：链接持久文档而不重复内容。
- 用户偏好语言版本使用目标语言标题。

禁止：Agent 实现规则；深度架构解释；PRD roadmap 重复；内部任务清单或 TODO；未验证命令或猜测的包管理器；默认放 backlog / 任务计划 / 命令转写链接。

## 更新模式

1. 保留准确的用户向内容。
2. 移除过期命令与失效链接。
3. 添加或修正模块与核心命令清单。
4. 链接设计与产品细节；不重复章节。

**文档集一致性**：README 更新绝不是孤立的。模块清单与核心命令必须匹配实际项目代码，并与项目 DESIGN 和 AGENTS.md 保持一致。README 改变项目是什么或做什么时，检查 DESIGN 与 AGENTS.md 中的过期陈述，受影响时对齐。

## 确认政策

写入或覆盖 `README.md` 前，呈现完整优化方案并取得用户明确确认。方案必须包含：目标文件路径；一句话项目描述；模块 / 核心命令概览；要添加/修改/移除的章节；要引用的规范文档。确认前不写、不覆盖、不重排正式英文 `README.md`。先生成用户偏好语言版本时，先更新它，再翻译正式英文版，保持语义对齐。

## 质量清单

- [ ] 目标项目根明确或安全推断
- [ ] README 是项目级，不是目录级
- [ ] 列出模块与核心入口命令，而非每个子命令
- [ ] 安装 / 运行 / 开发命令从项目文件验证
- [ ] 能力对用户可见
- [ ] 技术栈与项目结构未重复
- [ ] 持久参考已链接
- [ ] 无 Agent 规则内容
- [ ] 用户偏好语言版本先生成（非英文时）
- [ ] 用户偏好语言标题使用目标语言
- [ ] 写入前展示并确认完整优化方案
- [ ] 适用时确认后更新正式英文版

## 完成后回复

用用户语言回复：更新后的文件路径；变更摘要；已验证或缺失的命令；任何假设或缺失的持久参考。
