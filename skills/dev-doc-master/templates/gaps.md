This is a **process document**, not a long-lived design document. It records the gap between "what the implementation does today" and "what the design specifies", and it feeds planning. Entries are removed as the implementation catches up; once every gap closes, the document is deleted entirely.

The design truth lives in `./DESIGN.md`. This document does not restate it — it only describes divergence.
